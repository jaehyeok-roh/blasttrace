# sensor/ (담당: 상우 · 선우)

분광은 **도장 후 지적**(새 도막 위 의심 지점)에서만 씁니다. 검사원이 폰의 지적 카드에서 **"분광 측정"**을 누르면,
그 지적에 측정값이 바로 붙어 노트북 지적 화면에 판정·그래프가 뜹니다. `spectral.analyze()`는 지금 임시 규칙(640/515 nm 비)이고,
RF 모델로 바꿀 때 함수 이름과 반환 모양만 지키면 됩니다.

## 두 가지 모드 (서버를 켤 때 환경변수 `BT_SENSOR`)

| 모드 | 동작 |
|---|---|
| `sim` (기본) | 센서 없이 시연. 폰에서 누르면 시뮬레이터 값(`web/static/samples/spectral_*.csv`, **지어낸 값**)이 바로 들어가고, 화면에 "센서 시뮬레이터 (예시 값)"로 표시 |
| `device` | 폰에서 누르면 그 지적이 "센서 대기"가 되고, 센서가 아래 API로 보낸 값이 붙습니다 |

## 센서가 보내는 값 (`device` 모드)

센서 보드(ESP32 등, 같은 와이파이·핫스팟)가 측정 버튼을 누를 때마다 보냅니다.

```
POST http://<노트북 주소>:8000/api/sensor
Content-Type: application/json

{"white": [14개 숫자], "sample": [14개 숫자], "device": "AS7343-01"}
```

- `white` = 흰 기준면 원시 값(측정 시작 때 한 번 재서 보드가 기억), `sample` = 지적 위치 원시 값. 반사율 = sample / white.
- 폰에서 "분광 측정"을 먼저 누르지 않으면 `409`, 숫자가 14개가 아니면 `400`을 돌려줍니다. 성공하면 `{"finding", "label", "rust_index"}`.
- 서버는 측정을 `data/sensor.csv`에 두 줄(white, sample)로 쌓습니다. 열: `location_id, measured_at, ref, ch1~ch14, source`
  (형식 예시: `shared/sensor.csv`, 값은 지어낸 예시).
- 채널 순서와 파장은 센서 도착 후 라이브러리 실제 출력 순서로 고쳐 주세요.
  AS7343 데이터시트 기준 후보: 405, 425, 450, 475, 515, 550, 555, 600, 640, 690, 745, 855 nm + 밝기(clear) + 깜빡임.
